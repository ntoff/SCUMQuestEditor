# SCUM Quest Editor - General Information

All quest customizations require a server restart to be applied.

## Quest Files

Default quest customization can be generated by executing command #ExportQuests.

The following folders will be created:

- Saved\Config\<Platform>\Quests\QuestList - Contains DefaultQuestList.json with all currently loaded default Quest Names
- Saved\Config\<Platform>\Quests\QuestList - Contains CustomQuestList.json with all currently loaded custom json Quest Names
- Saved\Config\<Platform>\Quests\Override - Here you can create your own quests, one .json file per new quest
- Saved\Config\<Platform>\Quests\Blocked - Contains BlockQuests.json to control which quests are disabled

## Creating Custom Quests

Custom quests can be made by creating a .json file inside Saved\Config\<Platform>\Quests\Override folder for each custom quest.

You can use this editor to create valid quest JSON files that will work with SCUM.
